# Состояние перехода на полные ML-пайплайны

Предыдущая реализация сохранена в Git: контрольная точка `7963099`.
Это не резервная копия PostgreSQL.

## Завершённый этап

- Два кандидата: logistic_regression_tuned и decision_tree_tuned. GridSearchCV
  подбирает гиперпараметры; медианы вычисляются внутри pipeline. Поддержаны
  индивидуальные стратегии mean/median для будущих вариантов моделей.
- Текущий выпуск: `20260908T011221Z-80757f04`. Артефакты и снимок исходников
  хранятся через DVC; загрузка в Яндекс Диск и контрольные суммы проверены.
- Consumer выполняет фоновые прогнозы challenger. Полные pipeline проверяются
  по контрольным суммам при загрузке.
- Добавлены импорт исходного CSV в БД, снимки исследований с обратной связью,
  фильтр дат и обучение на снимках с разбиением по пациентам.
- Ноутбуки используют общие функции обучения. Настроено скачивание моделей
  через DVC перед тестами и сборкой в CI. Пользователь добавил GitHub Secrets.
- Проверка перед коммитом: 142 теста прошли, два предупреждения библиотек.

## Остаётся проверить и завершить

- Резервное копирование и миграция действующей БД; проверка всего пути с Kafka.
- Административный интерфейс, авторизация, кнопка снимка и скачивание CSV,
  управление ролями моделей и мониторинг качества по общей обратной связи.
- Согласование остальных секретов CI/CD и проверка workflow после публикации.
- Обработка длительных сбоев фоновых моделей: сейчас ошибка задерживает
  подтверждение сообщения; успешные прогнозы при повторе пропускаются.

`dvc.lock` сохраняет зависимости выполненного обучения, а исходный код после
выпуска дополнен. Текущие модели не переобучены новым кодом. Не заменять хеши
зависимостей старого обучения без фактического нового запуска.

Секреты `.env` и `.dvc/config.local` не входят в коммит.
